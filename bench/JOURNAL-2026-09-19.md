# Journal du 2026-09-19 — trois expériences, et ce qu'elles ont réfuté

*Écrit le jour même, avant toute réécriture de l'histoire. Ce document existe pour qu'on ne
reformule pas dans trois semaines « peut-être que… » sur des choses qui ont été mesurées.*

Toutes les mesures portent sur **un seul dépôt** (TAKIBO, commit `032788fb6d`, 782 fichiers Java,
~371 000 tokens de source) et **un seul modèle** (Opus 5, configuration par défaut — le niveau
d'effort n'était pas réglable pour les sessions filles). C'est la limite principale de tout ce qui
suit.

## Banc 1 — POC-01 : douze questions, agent seul contre agent + faits

Six exécutions, ordre `A1 B1 A2 B2 A3 B3`, sessions fraîches.

| | Points | Fausses affirmations | Tokens | Durée | Appels d'outil |
| --- | --- | --- | --- | --- | --- |
| A — agent seul | 24/24 (×3) | 0 | 144 127 | 361 s | 40,3 |
| B — agent + faits | 24/24 (×3) | 0 | 155 904 | 375 s | 27,7 |

**Aucun gain d'exactitude.** Le banc a saturé : les douze questions sont résolubles en lisant le
code. Les faits ont fait baisser l'exploration de 31 % et monter la consommation de 8 %.

Les trois sessions B ont dû **contredire le bundle** sur trois points : l'`ABSENCE` sur
`OrgBoundaryFilter` (le filtre est monté sur la chaîne, simplement inerte), et les deux « aucune
conclusion » que le graphe Gradle permet de lever.

Détail complet : `poc-01/RESULTATS.md`.

## Banc 2 — POC-02 : exhaustivité

Question unique : la liste complète des endpoints qui n'atteignent pas `PolicyEvaluator`.

| Bras | Tokens | Durée | Outils | Réponse | Les 8 vraies |
| --- | --- | --- | --- | --- | --- |
| A — agent seul | 120 419 | 352 s | 31 | 10 sur 47 | 8/8 |
| B — agent + faits bruts | 128 209 | 440 s | 35 | 12 sur 49 | 8/8 |
| C — agent + rendu compact | **104 193** | **321 s** | **22** | **8 sur 45, exact** | 8/8 |
| D — filtre sans modèle | **0** | **1 ms** | 0 | 8, dont 6 déclarés non conclus | 8/8 |

Trois mesures de taille, qui expliquent le reste :

| | Tokens estimés |
| --- | --- |
| Tout le Java du dépôt | ~371 400 |
| **Bundle brut de faits, 45 routes** | **~248 190** (67 % de la source) |
| Les deux configs de sécurité + le manager | ~5 834 |
| **Rendu compact, 45 routes** | **~2 767** (90× moins que le brut) |

Trois enseignements :

1. **Les faits bruts sont disqualifiés par leur taille.** Décrire coûte presque aussi cher que le
   code décrit. Le bras B a été le plus lent et le plus cher.
2. **Le rendu compact est le premier gain réel de la journée** : −13 % de tokens, −29 % d'appels
   d'outil, et la seule réponse exactement conforme à l'étalon.
3. **L'agent seul a battu Taxo sur l'exhaustivité.** Il a trouvé `@Endpoint(id="auditstores")`
   (`AuditStoreEndpoint.java:10,19,31`), deux opérations HTTP invisibles à un recensement des
   `@*Mapping` — donc invisibles à Taxo, et absentes de mon propre étalon.

## Banc 3 — POC-03 : diff entre deux commits

Fenêtre `8ac9f996` → `f18ff9ca`, 7 commits.

| | Taxo, déterministe | Agent seul |
| --- | --- | --- |
| Coût | **30,5 s, 0 token** | 503 s, 123 204 tokens |
| Surface : ajouts / retraits | 4 / 2 — **juste** | idem, plus 2 sondes actuator |
| **Changements de protection** | **0 signalé** | **4 réels, prouvés ligne à ligne** |

Les quatre changements manqués, dont deux revérifiés directement dans le code :

1. **`/actuator/**` passe de `permitAll` anonyme à autorité plateforme** — `SecurityConfig.java:52`
   avant, `:65-70` après. `POST /actuator/loggers/{name}` compris. *(vérifié)*
2. **Un contournement par percent-encoding est fermé** sur les 27 routes sous policy :
   `request.getRequestURI()` devient `UrlPathHelper.getPathWithinApplication()`. *(vérifié)*
3. **Clients OAuth2** : avant, aucune règle du `PolicyEvaluator` ne matchait `/api/orgs/**`, donc
   `POL_DEFAULT_ALLOW` ; après, règle explicite avec frontière de space.
4. **`signup`** : les organisations existantes sont désormais refusées.

**Pourquoi Taxo ne les voit pas** : son catalogue modélise une seule chose, quelle règle de
`SecurityConfig` gagne pour une route Spring MVC. Trois de ces quatre changements vivent ailleurs.

Un acquis technique réel au passage : avec une clé de comparaison portant sur **l'emplacement**
(fichier:ligne), le diff produit **34 faux positifs** — les règles s'étaient seulement décalées dans
le fichier. Avec une clé portant sur **la connaissance** (le verdict), il en produit **0**. La
doctrine de l'ADR 0005 sur l'identité est validée par un chiffre.

## Mes erreurs, à garder écrites

**Erreurs d'étalon** — corrigées en citant le code, jamais pour arranger un résultat :

| Où | Erreur | Correction |
| --- | --- | --- |
| POC-01 Q2 | « les rôles sont hors périmètre » | Faux : `PolicyEvaluator.java:111-117` teste quatre codes en dur. La couverture `OUT_OF_SCOPE` du POC est donc **une fausse absence**. |
| POC-01 Q10 | « indécidable, deux chaînes candidates » valait +2 | Faux : `takibo-adp-test/build.gradle:8` tranche. |
| POC-01 Q12 | « deux applications » | Incomplet : plus un troisième livrable exécutable, `takibo-install-keys`. |
| POC-02 | recensement de 45 endpoints | Incomplet : les opérations actuator n'y étaient pas, et ma question ne fixait pas la convention. |

Les deux premières erreurs figuraient aussi dans la vérité de référence du récit TAXO-POC-01,
écrite avant le POC.

**Erreurs de protocole :**

- **Contamination.** Au banc 2, le rendu compact avait été copié dans le dossier du bras « faits
  bruts ». B1 l'a lu : ce run mélange deux bras. Le bras B propre n'a pas été rejoué.
- **Réplicats.** Le banc 1 a trois exécutions par bras ; les bancs 2 et 3 n'en ont qu'une. Les
  écarts de tokens des bancs 2 et 3 sont cohérents mais pas solides statistiquement.
- **Archivage.** Les réponses brutes des sessions ne sont pas versées en fichiers ; elles vivent
  dans la transcription des sessions. Durées, tokens et appels d'outil sont relevés à la source.

## Ce qui est réfuté

- **« Taxo est la mémoire vérifiable qui manque aux agents. »** Sur ce dépôt, avec ce modèle, sur
  ces questions : trois bancs, trois fois l'agent seul a suffi.
- **« Taxo peut servir d'auditeur de sécurité déterministe en CI. »** Réfuté par le banc 3 dans le
  cas précis où il devait être utile. Un tableau de bord alimenté par ce POC aurait affiché
  « aucun changement de protection » sur une PR qui ferme un contournement d'autorisation.

## Ce qui n'est pas réfuté, et reste inconnu

- **Le régime d'échelle.** Tout ce dépôt tient dans une fenêtre de contexte. La thèse de Taxo a été
  écrite pour le cas inverse : un corpus qu'un agent **ne peut pas** lire en entier. Jamais testé.
- **Les modèles moins capables**, et le cas où il faut **prouver** une affirmation à un tiers
  plutôt que la savoir soi-même.
- **L'énumération exacte des dépendants d'un symbole** sur un très gros dépôt — la faiblesse du LLM
  y paraît structurelle et non conjoncturelle.

## Ce qui reste réutilisable

Contrat du fait et identité canonique, instantanés Git déterministes, diff sur la connaissance,
rendu compact, et la méthode : geler, écrire la vérité de référence avant, mesurer, corriger
l'étalon quand le code contredit.

**Ce qui n'existe pas**, et qu'il ne faut pas croire acquis : aucun index SCIP, aucun graphe de
symboles, aucun analyseur Java. Le patrimoine est petit — donc le coût d'arrêter l'est aussi.

## Décision du 2026-09-19

**Développement gelé.** Aucun TILES, aucun MCP, aucun analyseur Java, aucune nouvelle architecture.

**Une dernière expérience, une journée maximum**, sur le seul terrain non réfuté : l'énumération
exacte des dépendants d'un symbole, sur un dépôt qu'un agent ne peut pas lire en entier.

- Outillage : `scip-java`, qui existe déjà. **On ne développe rien.**
- Terrain : Keycloak.
- Question : tous les appelants directs et indirects pertinents d'un symbole transversal, et les
  impacts d'un changement de son contrat.
- Bras A : agent, dépôt, outils habituels. Bras B : même agent, plus l'index SCIP.
- Mesures : couverture réelle, omissions, appels d'outil, temps, tokens.

**Règle de décision, écrite avant le run :**

> Si l'index apporte un avantage net sur l'exhaustivité, ou réduit fortement le travail, Taxo est
> redéfini autour de l'intelligence d'impact logiciel. Si l'agent seul reste aussi bon, Taxo est
> archivé : `Taxo — archived: hypothesis disproved / insufficient differentiation`.

Archiver ne sera pas un échec. Six mois d'analyseurs auront été évités par une journée de mesures.
